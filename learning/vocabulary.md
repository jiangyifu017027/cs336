# CS336 英文术语表

只加入学习中实际遇到的词。优先记“语境含义”，不追求一次背大量词典释义。

| English | 中文 | 本文/课程中的含义 | 来源 | 复习状态 |
|---|---|---|---|---|
| language model | 语言模型 | 对 token 序列的概率分布建模；具体定义待第 1 讲学习确认 | 预设入学词汇 | 未学 |
| tokenizer | 分词器 | 在文本与 token ID 序列之间转换的组件 | 预设入学词汇 | 未学 |
| token | token / 词元 | 模型处理序列时的基本单位，不一定等于一个自然语言单词 | 预设入学词汇 | 未学 |
| vocabulary | 词表 | token 与 ID 映射所覆盖的集合 | 预设入学词汇 | 未学 |
| byte | 字节 | 8 bit；字节级分词可先从 UTF-8 编码理解 | 预设入学词汇 | 未学 |
| subword | 子词 | 介于字符/字节与完整单词之间的序列单位 | 预设入学词汇 | 未学 |
| Byte Pair Encoding (BPE) | 字节对编码 / BPE | 一种通过反复合并相邻对来构建分词单位的方法；细节待学习 | 预设入学词汇 | 未学 |
| end-to-end | 端到端 | 从输入到最终目标整体连接或训练；具体语境需结合原文 | 通用词汇 | 未学 |
