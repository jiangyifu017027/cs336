# AI 辅助学习使用说明

这套配置把 AI 定位为**中文助教 + 英文伴读 + 工程辅助 + 学习记录员**，而不是替你完成 CS336 的解题器。

## 第一次使用

在项目根目录启动或重载 AI 后，运行一次：

```text
/reload
```

这样它就能发现 `.agents/skills/` 中的本地 skills。之后可以用自然语言触发，也可以显式输入下面的命令。

## 四个 skills

| 场景 | 命令示例 | AI 会做什么 |
|---|---|---|
| 开始/结束/导航（日常主入口） | `/skill:cs336-review 继续上次学习` 或“作业里还要做哪些” | 记录进度、给出下一步、列出剩余作业题目；**不提问** |
| 概念讲解（你主动要求时） | `/skill:cs336-study 讲一下 BPE 训练` | 中文分层讲解、术语对照；讲完即止，不检查理解 |
| 读英文资料 | `/skill:cs336-english 带我做 A1 handout 的 BPE 部分，先解释题意和术语` | 中文速览、关键原文、长难句和术语，不给实现答案 |
| 作业导航/debug | `/skill:cs336-assignment A1 还剩哪些题` 或“我遇到了这个测试错误：……” | 列出剩余题目、分析证据、引导定位、review 你的代码 |

也可以直接说中文，例如“继续上次学习”“作业里还要做哪些”“讲一下 RoPE”“帮我分析这段报错”。显式 `/skill:` 命令用于确保调用指定流程。

## 推荐学习闭环（2026-11-25 调整）

1. **AI 指路**：每次开始时，AI 从 `progress.md` 的待办清单告诉你接下来做什么（包括作业里还没做的题），**不和你讨论目标、不做诊断**。
2. **你自学**：自己读讲义、写作业。需要讲解概念时主动说“讲一下 X”；英文障碍时说“翻译这段”。
3. **你跑测试**：作业命令由你自己执行，输出贴给 AI 分析。
4. **AI 记录**：结束时 AI 把实际做了什么、还剩什么写回 `progress.md` 和 session，**不追问理解程度**；掌握度由你自己在 `knowledge-map.md` 勾选。

> 每个作业仓库的官方 `AGENTS.md` 禁止 AI 写答案、代码/伪代码、完成 TODO、修改学生代码或代为运行 shell。因此“AI 处理辅助环节”不等于“AI 代做核心实现”。这能避免时间省了，核心能力却没有获得。

## 文件说明

```text
learning/
├── README.md             # 本说明
├── plan.md               # 总体计划、时间预算和滚动周计划（轻量版：主线 L01–L03 + A1 与概念线）
├── progress.md           # 当前学习位置、讲次/作业状态和下一步
├── knowledge-map.md      # 逐条知识点；AI 标已讲解，用户自评掌握度
├── questions.md          # 未解决与已解决问题
├── vocabulary.md         # 结合课程语境的英文术语表
├── reading/              # 长篇英文资料的分次阅读记录
├── templates/session.md  # 会话记录模板
└── sessions/             # 每次学习的实际记录
```

- `STATUS.md`：区分各电脑/环境的依赖、数据和资料状态；环境可用不代表课程已掌握。
- `learning/progress.md`：当前学习位置、实际讲解记录和下一步。
- `learning/knowledge-map.md`：AI 维护“已讲解”标记，你维护掌握度。
- `lectures/`：每讲的个人笔记。

## 你的分工

AI 尽量承担检索定位、翻译、资料摘要、记录整理、错误分类和反馈；你专注于**理解、写核心实现、判断掌握度和解释结果**。遇到不懂的内容可以直接说“换个例子”“只讲直觉”“逐句翻译”；只有你主动说“考考我”或“出几道题”时，才进入提问式检查。
