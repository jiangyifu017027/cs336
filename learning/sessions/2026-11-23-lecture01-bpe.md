## AI 辅助摘要

- 初始词表包含 0～255 的单字节 token，因此任意 UTF-8 文本都能先表示为已知 token，不需要因未见文本而退化为 UNK。
- 每轮训练只处理当前序列中的相邻 token 对：统计频次，选出最高频对，为它分配新 ID，再替换当前序列中的所有该相邻对。后续轮次可以继续合并新 token，因此 token 能逐渐表示更长的 byte 序列。
- 讲义例子 `the cat in the hat` 经 3 轮合并依次得到 `th`、`the`、`the␣`（`␣` 表示普通空格）；最终序列从 18 个单字节 token 缩短为 12 个 token。
- 训练产物分为两类：`vocab` 保存 token ID 到 bytes 的映射，用于 decode；`merges` 保存相邻 ID 对到新 ID 的映射及其顺序，用于 encode。
- 编码新文本时先转成 UTF-8 bytes，再按训练时的顺序应用 merges；未命中合并规则的部分保留为更小的已知 token。解码时查 vocab、拼接 bytes，再做 UTF-8 解码，可恢复原字符串。
- 讲义列出的 A1 增强：只处理相关 merges、识别并保留 special tokens、使用 pre-tokenization、提高速度。本次只讲目的，不给实现方法。
